# 字符串(Strings)

Rust 有两种字符串类型：一种是字符串切片（slice）（`&str`），另一种是拥有所有权的字符串（`String`）。
我们不会规定你应该何时使用哪一种，但我们会向你展示如何区分、创建以及使用它们。
