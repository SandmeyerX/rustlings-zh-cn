# 字符串(Strings)

Rust有两种字符串类型：一种是字符串切片(slice)(`&str`)，另一种是自身拥有所有权的字符串(`String`)。
我们不会规定你应该何时使用哪一种，但我们会向你展示如何识别、创建它们以及如何使用它们。
