# 哈希表(Hashmaps)

*哈希表（hash map）* 允许你将一个值与特定的键相关联。
你可能也知道在 C++ 中它被称为[*无序映射（unordered map）*](https://zh.cppreference.com/w/cpp/container/unordered_map)，
在 Python 中被称为[*字典（dictionary）*](https://docs.python.org/zh-cn/3/tutorial/datastructures.html#dictionaries)，或者在其他语言中被称为*关联数组（associative array）*。

这是我们之前在讨论动态数组（Vecs）时提到过的另一种数据结构。
