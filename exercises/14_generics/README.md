# 泛型(Generics)

泛型的核心作用是将类型与功能进行抽象通用化，使其能泛化到更广泛的场景。
它能从多方面极大地减少代码冗余，但对应的语法会相对复杂。
具体来说，使用泛型时需格外注意指明泛型类型实际对哪些类型是合法有效的。
泛型最简单且最常见的用途是作为类型参数。
