# 宏（Macros）

Rust 的宏系统非常强大，但也有些难以理解。我们不打算教你如何编写功能完备的宏。相反，我们会向你展示如何使用和创建它们。

如果你想进一步学习如何编写自己的宏，[macrokata](https://github.com/tfpk/macrokata) 项目提供了与 Rustlings 风格类似的练习，但全部聚焦于宏的编写。
